## Files

- `env.json`, `env_end.json` — host, kernel, tool versions, and binary SHA-256 at the start and end of the run.
- `b01_cold_start.json` (`raw/b01_*.json`, `raw/b01_*.jsonl`) — cold start ($N = 10,000$ per participant).
- `b02_tls_handshake.json` (`raw/b02_client_ours.jsonl`, `raw/b02_node_ours.jsonl`) — TLS 1.3 handshake ($N = 10,000$) and reverse node link registration ($N = 1,000$).
- `b03_rss_idle.json` (`raw/b03_*.json`, `raw/b03_*.jsonl`) — idle RSS and PSS ($20 \times 0.5\text{ s}$ samples).
- `b05_exec_latency.json` (`raw/b05_*.json`, `raw/b05_*.jsonl`) — warm `exec` round-trip latency ($N = 10,000$ per participant).
- `b07_per_connection.json` (`raw/b07_*.json`, `raw/b07_ours.jsonl`) — RSS scaling across $20$ concurrent client connections.
- `b08_footprint.json` — on-disk binary, environment, and runtime footprint.
- `summary.md` — rendered summary generated by `bench/lib/summarize.py`.
